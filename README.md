# OMR Optik Form Okuyucu

T.C. Millî Eğitim Bakanlığı stajım kapsamında geliştirilen, optik formları işlemek ve değerlendirmek amacıyla tasarlanmış masaüstü veri çıkarma ve dijitalleştirme modülüdür.

## 🚀 Özellikler
* **Koordinat Haritalandırma:** Form koordinatlarını JSON formatında işaretleyerek optik sonuçların doğru bir şekilde okunması.
* **Görüntü İşleme & Dijitalleştirme:** Kağıt üzerindeki işaretlemelerin hassas bir şekilde analiz edilip dijital verilere dönüştürülmesi.
* **SQL Entegrasyonu:** Elde edilen verilerin güvenilir veri yönetimi odaklı olarak SQL veritabanlarına sorunsuz aktarımı.

## 🛠️ Kullanılan Teknolojiler
C# | WPF | SQL | JSON
